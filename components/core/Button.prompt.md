Primary action control; one primary per view (e.g. "ยืนยันการนัดหมาย").
```jsx
<Button variant="primary" size="lg" iconLeft="calendar-check" fullWidth>ยืนยันการนัดหมาย</Button>
<Button variant="secondary">ย้อนกลับ</Button>
```
- Variants: primary (teal), secondary (white + border), ghost, danger, soft (teal tint).
- `loading` swaps the left icon for a spinner and disables. Press shrinks to 0.98.
